# wisp-platform

L1 of the [`wisp`](https://github.com/chiiydd/wisp) workspace — distro, package-manager and init-system trait abstractions. Arch is implemented today; the traits are designed for Debian / Fedora / openSUSE to slot in without touching higher layers.

See the [main README](https://github.com/chiiydd/wisp#readme).
